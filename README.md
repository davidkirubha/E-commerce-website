# SHOPZONE – E-Commerce Website

A modern and responsive E-Commerce frontend website built using React.js.

## 🌐 Live Demo
[Click here to visit SHOPZONE](https://e-commerce-website-sage-sigma.vercel.app)

## ✨ Features
- Responsive Home Page
- Featured Products
- Product Listing
- Search Products
- Category Filtering
- Add to Cart
- Increase / Decrease Product Quantity
- Remove Products from Cart
- Wishlist

## 🛠️ Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite

## 💻 Run Locally

```bash
git clone https://github.com/davidkirubha/E-commerce-website.git
cd E-commerce-website
npm install
npm run dev
```
